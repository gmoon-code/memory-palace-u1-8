THE STORY METHOD - CONTENT STUDIO
TEACHER START HERE

This package installs the validated Content Studio v1.0.0 local teacher workspace on Windows.

WHAT YOU NEED

1. Windows 10 or Windows 11
2. Free Python 3.10 or newer
3. Free Git for Windows
4. An internet connection during the first installation and dependency setup

No paid hosting, paid persistent storage, paid API, subscription, billing account, or payment method is required.

INSTALL

1. Extract this ZIP to a normal folder such as Downloads.
2. Keep all files from this package together.
3. Double-click "Install Content Studio.cmd".
4. Press Enter to accept the default folder
   C:\Users\<your-name>\Story Method Content Studio
   or type another empty folder.
5. The installer clones only the official repository and pins the validated teacher runtime.
6. Content Studio then starts its normal first-time owner setup.
7. Create your local owner username and a password of at least 12 characters.
8. Your browser opens to the local Content Studio.

Content Studio binds to 127.0.0.1 and runs on your own computer.

The installer refuses to overwrite an existing non-empty installation folder. Existing Content Studio data should be maintained with the normal Backup, Restore, Repair, and Update launchers inside the installed repository.
