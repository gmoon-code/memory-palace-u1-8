## U4-J4 — Feedback Regulation Center

- **Homeostatic control-loop anatomy** — Homeostasis Control Map → Sensor–Integrator–Effector Loop
- **Negative-feedback control** — Negative-Feedback Thermostat → Blood-Glucose Regulator

## U4-J5 — Cell-Cycle Preparation Archive

Genome and chromosome organization, ploidy, interphase, G1, S, G2, G0, and chromosome-count logic across replication

Setting logic — An archive-to-clock route prepares the learner to understand mitosis by first making chromosome identity, replicated structure, ploidy, and cell-cycle phase changes stable and visible.

- **Genome and chromosome organization** — Genome Packing Archive → Chromosome Anatomy Workbench → Chromosome Sets Gallery
- **Interphase and cell-cycle states** — Cell-Cycle Clock → G1 Growth Gate → S-Phase Replication Room → G2 Preparation Bay → G0 Side Chamber

## U4-J6 — Mitosis Transit Hall

Mitosis purpose and sequence, spindle formation, prometaphase, metaphase, anaphase, telophase, chromosome counting, and animal/plant cytokinesis

Setting logic — A physical transit hall follows the same replicated chromosomes from condensation through attachment, alignment, separation, nuclear reassembly, and cytoplasmic division.

- **Mitotic chromosome movement** — Mitosis Mission Control → Prophase Spindle Setup → Prometaphase Kinetochore Access → Metaphase Plate Station → Anaphase Separation Track → Telophase Reassembly Room
- **Cytokinesis mechanisms** — Animal Cytokinesis Ring → Plant Cell-Plate Works

## U4-J7 — Cell-Cycle Security Headquarters

Checkpoints, arrest, DNA-damage response, apoptosis, cyclin-CDK control, extracellular growth constraints, cancer, tumors, metastasis, and carcinogen risk

Setting logic — A security headquarters treats cell-cycle progression as a sequence of permission decisions, then shows how signaling and regulatory failures can produce uncontrolled proliferation and cancer progression.

- **Checkpoint decisions and cell safety** — Checkpoint Command Map → G1 Commitment Gate → G2 DNA-Integrity Gate → Spindle-Assembly Checkpoint → Apoptosis Safety Exit
- **Cyclin control and external proliferation cues** — Cyclin–CDK Control Rack → Growth and Attachment Signals Bay
- **Cancer-control failure and progression** — Cancer Control-Failure Board → Tumor Progression Corridor → Carcinogen Risk Bay
