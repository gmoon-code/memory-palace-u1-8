## Key F2 decisions

The permanent palace is reserved for durable evolutionary mechanisms, scientific identities, comparison structures, population-level relationships, evidence categories, and teacher-required terminology. The architecture explicitly keeps mutation, drift, gene flow, selection, Hardy-Weinberg concepts, homology, phylogeny, speciation barriers, and origin-of-life models in stable visual locations.

The 16 PRACTICE_ONLY records remain outside permanent loci. These include Hardy-Weinberg calculations, graph interpretation, drift/gene-flow scenario classification, evidence synthesis, cladogram construction, reproductive-isolation discrimination, FRQ reasoning, and origin-of-life evidence application.

The 25 scope guards remain non-runtime constraints. They prevent teleology, strongest-equals-fittest shortcuts, individual-evolution language, random-selection framing, Hardy-Weinberg symbol misuse, universal carbon-14 claims, functionless-vestigial wording, primitive-lineage language, overbroad species-concept use, and origin-of-life misconceptions.
