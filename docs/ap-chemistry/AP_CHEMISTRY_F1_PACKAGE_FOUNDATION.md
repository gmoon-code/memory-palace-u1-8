# AP Chemistry F1 package foundation

## Status

F1 is complete. The two-unit architecture fixture has been replaced by the real nine-unit AP Chemistry development package foundation.

This phase establishes structure only. It does not create production narratives, scenes, Memory Objects, review questions, mixed-discrimination sets, or Challenge Lab items.

## Locked package structure

The live AP Chemistry package now follows the CED Unit 1 through Unit 9 order and contains all 91 CED topic boundaries from the completed F0B crosswalk.

Every unit has package-declared empty runtime scaffolds for journeys, concepts, Memory Objects, review, mixed discrimination, and Challenge Lab content. Empty means intentionally unproduced at this phase. It does not mean the feature is removed.

## Source boundary

The package foundation takes unit and topic membership directly from the F0B framework crosswalk. F0C controls later science-component coverage. F0D authorizes production. The CED/public College Board laboratory source basis controls later lab planning.

PPT numbering remains non-structural. Zumdahl 11e remains the chemistry-accuracy reference. The seven F0B source-gap guards remain in force.

## Fixture retirement

The architecture-only journeys `APCHEM-U1-J1` and `APCHEM-U2-J1` are removed from the live AP Chemistry content tree. Their content is not promoted into the real course.

The old Unit 2 fixture title `Molecular and Ionic Compound Structure and Properties` is replaced by the current locked CED title `Compound Structure and Properties`.

The historical architecture fixture remains recoverable through the frozen multi-course foundation checkpoint and does not need to remain in the active course tree.

## Runtime locks

AP Chemistry remains `development`, `student_visible=false`, catalog-ready, and read-only in Content Studio. The static student-site builder therefore continues to exclude AP Chemistry.

## Next phase

F2 begins real Unit 1 academic production. It will build the Unit 1 scientific catalog and journey architecture from CED Topics 1.1 through 1.8, using the mapped teacher-PPT depth, Zumdahl 11e chemistry reference, F0C component requirements, and assessment evidence. Narrative scenes remain downstream of the scientific catalog and journey architecture.
