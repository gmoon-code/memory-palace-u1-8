The route is strictly sequential across the CED. The first planned journey moves from measurable mass through isotope evidence and composition. The second builds electron structure and then tests it with PES. The third uses a common electrostatic/electron-structure model to explain periodic trends. The fourth converts valence patterns into ionic-charge and formula reasoning.

These are spatial/scientific plans, not finished stories. No guide character, mnemonic actor, scene prose, or finale is locked in F2. Later narrative work must make each location vivid and causally connected without changing the scientific catalog.
