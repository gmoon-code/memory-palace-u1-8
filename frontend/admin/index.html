What Step 2 protects

  • Production main remains unchanged.
  • The admin interface remains disabled unless explicitly enabled on a trusted server.
  • Teacher access requires configured credentials and a server-side session.
  • Protected actions require a session-specific CSRF token and same-origin checks.
  • Failed sign-ins are rate limited without storing raw client addresses.
  • Authentication and security events are recorded in the server-side audit database.
  • No content write API exists yet.
  • The GitHub Pages student deployment still excludes the admin interface.
